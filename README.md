# CryptoCore

Инструмент для шифрования и дешифрования AES-128 в режиме ECB

## Установка (Windows)
```bash
git clone https://github.com/desolatttte1212/CryptoCore.git
python3 -m venv venv
source venv/bin/activate
pip install -e .
cryptocore --help
```

### CLI-2
Аргументы команды dgst:
```bash
--algorithm ALGORITHM — поддерживает sha256, sha3-256, sha3_256
--input INPUT_FILE — путь к файлу для хеширования
--output FILE (опционально) — запись хеша в файл
```

### CLI-3
Команда dgst не принимает аргументы шифрования (--key, --mode, --encrypt и т.д.).

### CLI-4
Формат вывода соответствует стандарту *sum:

```text
<хеш_в_нижнем_регистре> <путь_к_файлу>

Пример:
e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855 document.pdf
```

### CLI-5
Поддерживается флаг --output для записи хеша в файл.

### HASH-1
SHA-256 реализован с нуля:

Соответствует NIST FIPS 180-4
Merkle-Damgård конструкция с 512-битными блоками
Корректный padding (1 + нули + 64-битная длина)
Все константы и раундовые функции реализованы вручную

### HASH-2
Второй алгоритм — SHA3-256 (через hashlib), что разрешено требованием HASH-3.

### HASH-4 / HASH-5
Поддержка файлов любого размера:

Чтение чанками (8192 байт)
Постоянное использование памяти (O(1))

### HASH-6
Хеши выводятся в нижнем регистре (hex-строка).

### IO-1 / IO-2 / IO-3
Чтение в бинарном режиме ('rb')
Обработка ошибок (отсутствующий файл и т.д.)
Запись в файл через --output в том же формате

# Примеры использования (дополнены)
### Хеширование файла
```bash
cryptocore dgst --algorithm sha256 --input document.txt
```
### Хеширование с записью в файл
```bash
cryptocore dgst --algorithm sha3-256 --input backup.tar --output backup.sha3
```
